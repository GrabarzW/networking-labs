\# Static Routing



\## Objective



Configure IPv4 addressing and static routes on Cisco routers to establish end-to-end connectivity between two networks.



\## Tasks



* Configured IPv4 addresses on the routers and PCs.
* Configured default gateways on the PCs.
* Configured static routes on the routers.
* Verified end-to-end connectivity between PC1 and PC2.



\## Cisco IOS Commands



* `ip address`
* `ip route`
* `show ip route`
* `show ip interface brief`
* `ping`



\## Concepts



* IPv4 addressing
* Default gateways
* Routing tables
* Static routes
* Next-hop routing
* End-to-end connectivity



\## Verification



Connectivity between PC1 and PC2 was verified using ICMP ping after configuring the required static routes.



\## Skills Demonstrated



* Cisco IOS CLI
* IPv4 configuration
* Static routing
* Routing table analysis
* Network connectivity verification
