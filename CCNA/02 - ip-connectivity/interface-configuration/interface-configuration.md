\# Interface Configuration and Hardening



\## Objective



Configure and document Cisco router and switch interfaces, manually set

Ethernet parameters where required, and disable unused interfaces.



\## Tasks



* Configured hostnames on R1, SW1, and SW2.
* Configured IPv4 addressing on the router and end devices.
* Manually configured speed and duplex on interfaces connected to network infrastructure.
* Added descriptions to network interfaces.
* Disabled unused interfaces.



\## Cisco IOS Features



* Hostname configuration
* IPv4 addressing
* Interface descriptions
* Speed configuration
* Duplex configuration
* Interface shutdown
* Interface verification

* Interface configuration
