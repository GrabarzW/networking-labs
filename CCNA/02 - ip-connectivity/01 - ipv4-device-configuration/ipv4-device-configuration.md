\# IPv4 Interface Configuration



\## Objective



Configure IPv4 addressing on a Cisco router and end devices, enable

router interfaces, and verify end-to-end network connectivity.



\## Tasks



* Configured the router hostname.
* Inspected router interfaces and their operational status.
* Assigned IPv4 addresses to router interfaces.
* Enabled router interfaces.
* Added interface descriptions.
* Verified interface configuration and status.
* Inspected the running configuration.
* Saved the configuration to startup configuration.
* Configured IPv4 addresses on PC1, PC2, and PC3.
* Verified end-to-end connectivity using ICMP ping.



\## Cisco IOS Commands



* show ip interface brief
* show running-config
* interface <interface>
* ip address <ip-address> <subnet-mask>
* description <description>
* no shutdown
* copy running-config startup-config



\## Concepts



* IPv4 addressing
* Subnet masks
* Router interfaces

* Interface descriptions
* End-device IP configuration
* ICMP connectivity testing
* Running vs startup configuration



\## Verification



* Connectivity was verified using ICMP ping between the configured
* end devices.
