\# Static Routing Troubleshooting



\## Objective



Identify and correct static routing misconfigurations preventing communication between two networks.



\## Scenario



PC1 and PC2 are unable to communicate with each other.



Each router contains one routing misconfiguration that must be identified and corrected.



\## Tasks



* Analyze the network configuration.
* Identify the routing misconfiguration on each router.
* Correct the static routing configuration.
* Verify end-to-end connectivity between PC1 and PC2.



\## Concepts



* Static routing
* Routing tables
* Next-hop addresses
* Network reachability
* End-to-end connectivity
* Routing troubleshooting



\## Verification



ICMP connectivity between PC1 and PC2 was tested before and after correcting the configuration.



The lab was completed when PC1 successfully pinged PC2.



\## Skills Demonstrated



* Cisco IOS CLI
* Static routing
* Routing table analysis
* Configuration troubleshooting
* Root-cause identification
* Network connectivity verification
