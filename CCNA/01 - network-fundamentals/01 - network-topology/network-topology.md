\# Network Topology



\## Objective



Build a multi-device network topology in Cisco Packet Tracer and establish basic physical connectivity between network infrastructure and end devices.



\## Devices



* 2× PCs
* 2× Servers
* 2× Cisco 2960-24TT switches
* 2× Cisco 2911 routers
* 1× Cisco 2911 router simulating the Internet
* 2× Cisco ASA 5505 firewalls
* 1× Laptop



\## Tasks



* Added the required network devices to the topology.
* Created the network topology according to the provided design.
* Connected the devices using Packet Tracer's automatic connection type selection.



\## Skills Demonstrated



* Cisco Packet Tracer
* Network topology design
* Basic device connectivity
* Identification of network infrastructure components
* Understanding of basic network architecture
