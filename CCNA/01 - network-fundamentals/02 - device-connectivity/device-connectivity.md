\# Device Connectivity



\## Objective



Connect network devices using the appropriate cable types based on the device interfaces and connection requirements.



\## Tasks



* Identify the appropriate cable type for each connection.
* Connect network devices according to the provided topology.
* Apply Ethernet and fiber-optic cabling rules.



\## Concepts



* Straight-through Ethernet cables
* Crossover Ethernet cables
* Single-mode fiber
* Multimode fiber
* Ethernet interfaces
* Fiber-optic interfaces



\## Skills Demonstrated



* Cisco Packet Tracer
* Network device connectivity
* Ethernet cabling
* Fiber-optic cabling
* Physical layer fundamentals
