\# OSI Model Traffic Analysis



\## Objective



Analyze network traffic in Cisco Packet Tracer Simulation Mode and identify the OSI model layers involved in different types of communication.



\## Tasks



* Analyzed network traffic using Simulation Mode.
* Examined packet details at different stages of communication.
* Identified the OSI layers involved in network traffic.
* Released and renewed the PC1 IP address to generate DHCP traffic.
* Analyzed DHCP communication at the protocol and OSI layer level.



\## Protocols Analyzed



* DHCP
* ARP
* ICMP
* Ethernet



\## Concepts



* OSI model
* Encapsulation and decapsulation
* Packet inspection
* DHCP address assignment
* Layer 2 and Layer 3 communication



\## Skills Demonstrated



* Cisco Packet Tracer Simulation Mode
* Network traffic analysis
* OSI model analysis
* Protocol identification
