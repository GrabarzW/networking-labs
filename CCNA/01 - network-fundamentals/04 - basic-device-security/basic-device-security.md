\# Basic Cisco Device Security



\## Objective



Configure basic security controls on Cisco IOS devices and verify how credentials are stored in the device configuration.



\## Devices



Cisco router R1

Cisco switch SW1



\## Tasks



* Configured device hostnames.
* Configured an unencrypted enable password.
* Verified password protection when entering privileged EXEC mode.
* Inspected the running configuration.
* Enabled password encryption.
* Configured an encrypted `enable secret`.
* Verified the difference between `enable password` and `enable secret`.
* Identified Cisco password encryption types.
* Saved the running configuration to the startup configuration.



\## Cisco IOS Features



* `hostname`
* `enable password`
* `enable secret`
* `service password-encryption`
* `show running-config`
* `copy running-config startup-config`



\## Security Concepts



* Privileged EXEC authentication
* Password encryption
* `enable password` vs `enable secret`
* Cisco password type 5
* Cisco password type 7
* Running vs startup configuration



\## Skills Demonstrated



* Cisco IOS CLI
* Basic device hardening
* Configuration verification
* Credential protection
* Configuration persistence
